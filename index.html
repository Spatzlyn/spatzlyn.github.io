My research asks what a robot's internal model must keep track of for its safety checks to be trusted.

A safety check can only rule out the hazards its model still represents. In my current project on occlusion-aware planning, the planner's model quietly dropped positions a hidden person could occupy, so a check that ran correctly still approved unsafe actions. I'm now extending the question to other approximations — merged states, simplified dynamics, learned world models — and to robots that work alongside people.

Before robotics, I kept running into the same gap between what a system appears to do and what it actually does: in how language models ground answers in evidence, in a model-compression challenge, and in auditing AI hiring assessments. I now bring that habit — asking what a check actually establishes — to robot safety.

Safety Evaluation in Occlusion-Aware Planning

Self-initiated independent research

Asked whether an occlusion-aware planner's apparent drop in uncertainty about a hidden person came from real evidence or from computation it had skipped. Built an independent trajectory reference with exact rational-arithmetic propagation of position–speed states and compared it against the planner's own model. A rule for avoiding repeated calculations turned out to discard feasible hidden positions, so they never reached the downstream safety check. In a separate checker experiment, restoring them cut the actions the safety check permitted from all 18 candidates to 4.

Evidence Grounding and Control in LLMs

Undergraduate Researcher · System Intelligence Group, Korea University

Studied whether language models commit to an answer before the evidence supports it, using controlled QA experiments that separate evidence access, answer commitment, and semantic support. Attention to question-matched distractors did not indicate real support, which motivated an intervention triggered by pre-answer logits combined with a semantic support score.

2025.09 — 2026.01

Auditing Proxy Information and Fairness in AI-Based Assessment

Independent research · began in an AI Ethics course

Built a four-level audit protocol for cognitive-science-based hiring assessments, with public Human Connectome Project cognitive-task data standing in for real applicant data. The audit tests proxy recoverability, fairness across selection rates, and mitigation costs. Gender remained predictable from task scores, a rule's apparent fairness shifted with how many candidates it selected, and in some cases reducing gender disparities raised age disparities.

Vision-Language Model Compression

Individual project · Samsung SCPC 2025 AI Challenge · code & report ↗ · announcement ↗

Built an A-OKVQA system on my own under a 3B-parameter limit, compressing InstructBLIP-Flan-T5-XL from 4.023B to 2.987B parameters with structured pruning, knowledge distillation, and a custom LoRA implementation; the solution reached 86.59% public weighted accuracy. Answer selection stayed accurate, but the compressed model's language generation weakened — something the leaderboard score never registered.
